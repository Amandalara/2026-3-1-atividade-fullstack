### Componentes e tecnologias

O projeto foi estruturado em duas partes conectadas por API:

- React + TypeScript para a interface web do frontend
- Vite como ferramenta de desenvolvimento e build do frontend
- Node.js + Express para a API RESTful do backend
- TypeScript em ambos os lados para manter a aplicação mais organizada e segura
- CORS para permitir a comunicação entre o frontend e o backend em ambiente local
- CSS moderno para criar a identidade visual mobile first com a paleta inspirada no DIATINF/Infoweb
- Armazenamento em memória no backend para simular o comportamento de um sistema de publicações com comentários e avaliações
